═══════════════════════════════════════════════════════════════════════════════
                              DATA FLOW SEQUENCE
═══════════════════════════════════════════════════════════════════════════════

1️⃣  USER INTERACTION
    └─► User opens http://localhost:8000
    └─► Sees beautiful web interface
    └─► Enters query: "Tesla"
    └─► Clicks "Search News"

2️⃣  MANAGER RECEIVES REQUEST
    └─► POST /run {"query": "Tesla"}
    └─► Validates request
    └─► Initiates pipeline

3️⃣  SEARCH PHASE
    └─► Manager → Search Service (8001)
    └─► POST /run {"query": "Tesla"}
    └─► Search Service:
        ├─ Creates ADK session
        ├─ Runs search_agent with google_search tool
        ├─ Extracts 10+ headlines from Google
        ├─ Formats response
        └─ Returns: {"headlines": [...], "meta": {...}}

4️⃣  SENTIMENT PHASE
    └─► Manager extracts headline texts
    └─► Manager → Sentiment Service (8002)
    └─► POST /run {"headlines": ["...", "..."]}
    └─► Sentiment Service:
        ├─ Creates ADK session
        ├─ Runs sentiment_agent with Gemini AI
        ├─ Analyzes each headline
        ├─ Classifies sentiment (positive/negative/neutral)
        └─ Returns: {"sentiment_summary": {...}, "per_item": [...]}

5️⃣  REPORT GENERATION
    └─► Manager combines results
    └─► Generates comprehensive report:
        ├─ Sentiment Summary (with counts)
        ├─ Fact Check Report
        ├─ Bias Check Report
        └─ Forensic Analysis Report

6️⃣  RESPONSE TO USER
    └─► Manager returns complete JSON
    └─► Browser JavaScript receives data
    └─► Displays formatted sections:
        ├─ 📊 Sentiment Analysis (stats + per-headline)
        ├─ 📰 Headlines (numbered list)
        ├─ ✅ Fact Check Report
        ├─ 🔍 Bias Check Report
        ├─ 🕵️ Forensic Analysis
        └─ 📋 Full JSON Response


═══════════════════════════════════════════════════════════════════════════════
                            TECHNOLOGY STACK
═══════════════════════════════════════════════════════════════════════════════

Backend Framework:
  • FastAPI (Python 3.9+)
  • Uvicorn (ASGI server)
  • Pydantic (data validation)

AI/ML:
  • Google ADK (Agent Development Kit)
  • Google Gemini 2.5 Flash (LLM)
  • Google Search API

HTTP Client:
  • httpx (async HTTP)
  • tenacity (retry logic)

Frontend:
  • Vanilla JavaScript
  • HTML5 + CSS3
  • Responsive design

Data Format:
  • JSON (API communication)
  • Pydantic models (validation)

Logging:
  • Python logging module
  • INFO level for operations
  • ERROR level for failures
